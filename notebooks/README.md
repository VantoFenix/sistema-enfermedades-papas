# Jupyter Notebooks (`notebooks/`)

Directorio dedicado a la exploración de datos, experimentación interactiva y prototipado rápido.

## Contenido Actual

- `01_eda.ipynb`: Notebook para el análisis exploratorio de datos (EDA), distribución de clases y características morfológicas.
- `02_preprocesamiento_senales.ipynb`: Pruebas interactivas de transformaciones de señales de imagen (ej. filtros, CLAHE, HSV).
- `03_baseline_clasico.ipynb`: Implementación interactiva del modelo *baseline* (SVM lineal + Extracción manual de características con HOG/HSV) para tener una métrica base con la cual comparar el rendimiento de las redes neuronales profundas.
